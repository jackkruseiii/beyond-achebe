# Site audit — 14 October 2026

Scope: the live repo (`jackkruseiii/beyond-achebe`, commit `8dcc123`), the rendered site at desktop and phone widths, every entry in `books.js`, and spot checks of outbound links.

**State at audit:** 54 countries · 37 read · 0 reviews pending · 17 to go · 17 poems chosen.

---

## 1. Fixed in this change

### Structure & repo
- Split the 728-line `index.html` into markup (`index.html`), styling (`assets/site.css`), atlas logic (`assets/atlas.js`) and the suggestion form (`assets/feedback.js`). `books.js` stays at the root so routine updates are still one file.
- Added `README.md` (how it works, field reference, update steps), `CLAUDE.md` (standing rules for Claude sessions), `.gitignore` (blocks `index (1).html`-style duplicates).
- Added `scripts/validate.js` and a GitHub Action that runs it on every upload, so a broken `books.js` shows a red ✗ on the commit instead of a blank atlas.

### Page
- **Phones had no navigation** — the nav links were hidden below 768px. They now show, compacted.
- **Horizontal scroll on phones** — long names (Equatorial Guinea, Congo (Republic)) pushed the "Reviewed" badge past the card edge. Badge now wraps.
- **Developer text visible to the public** — if the map failed, readers saw "Upload map.jpg to your GitHub repo". Replaced.
- **Link previews** — no Open Graph tags, so links shared by text or LinkedIn showed no image or description. Added (uses the map), plus favicon, canonical URL, `sitemap.xml`, `robots.txt`, and a `404.html` that sends lost visitors back to the atlas.
- **Fragile rendering** — cards were built with hand-escaped `onclick="showDetail('…')"` strings, which only worked for Côte d'Ivoire and the two Congos through a fallback. Now uses data attributes, delegated events, and escapes all text.
- **Keyboard & screen reader** — tags weren't reachable by keyboard; Space didn't open a card; no Escape to close; no focus outlines; region tabs didn't report which was active. All fixed.
- **Shareable entries** — opening a card now puts `?country=…` in the address bar, so any entry can be copied and sent. Existing deep links (Dad's Bookshelf) unchanged.
- "Maghreb" tab and legend now read **North Africa**, since Egypt sits there. The data key `maghreb` is unchanged.
- Map image now declares its size and loads lazily (no layout jump).
- All 33 `http://` blog links upgraded to `https://`.

## 2. Open decisions — need Jack

1. **Three dead "Read full review" links.** Cameroon (*Behold the Dreamers*), Tanzania (*Afterlives*) and South Africa (*The Promise*) point to `beyondachebe.com/2021/…`-style blog paths. Since the domain moved to GitHub Pages these 404 (they now land on the new 404 page). The same paths don't exist on fuuo.blogspot.com. **Need:** the current URLs for those three posts.
2. **Mauritius shows the wrong book.** *The Restraint of Beasts* (Magnus Mills) is a Scottish novel about fence-builders, unrelated to Mauritius. Mauritian options: Nathacha Appanah, *The Last Brother*; Ananda Devi, *Eve Out of Her Ruins*.
3. **Somalia poem doesn't match its link.** The card shows K'Naan, "Somalia"; the linked post features Abdirashid Omar's "Fatwo". Pick one and confirm the clip text.
4. **Poem clips to verify against your Poet of the Week posts.** Several clips couldn't be matched to the published poems and may be paraphrased rather than quoted: Soyinka "In the Small Hours", Rabearivelo "9", Konie, Chipasula, Dipoko, El Ouazzani, Mattawa, Tati Loutard, Seboni. (Algeria's *Kassaman* is usually rendered "We swear by the lightning…", not "We pledge".) Given the own-words rule, worth a pass.
